# Welcome to My Cybersecurity Portfolio

**Hey there! Stephen here!** 👋 Welcome to my **Cybersecurity Portfolio**, a collection of my hands-on cybersecurity labs, activities, exercises, and practical learning experiences from the **Google Cybersecurity Certificate**.

This portfolio represents my journey in developing the foundational knowledge and technical skills needed to pursue a career in cybersecurity. ## 🔐 Managing Security Risks

One of the first areas explored in my cybersecurity journey is **security risk management**. In this section, I learned how organizations identify potential security risks, assess their possible impact, and implement appropriate controls to reduce those risks.

I explored important cybersecurity concepts such as the **CIA Triad—Confidentiality, Integrity, and Availability**, security controls, risk assessment, policies, procedures, and security frameworks. I also learned that cybersecurity is not only about preventing attacks but also about understanding the risks an organization faces and determining how those risks can be managed effectively.

Through these activities, I developed a better understanding of how security professionals think about protecting organizational assets and making informed security decisions.

## 🌐 Networks and Network Security

The **Networks and Network Security** section focuses on understanding how computers communicate and how those communications can be protected.

In these labs, I explored networking concepts such as IP addresses, network protocols, ports, TCP/IP, DNS, HTTP/HTTPS, and network traffic. I also learned how attackers can take advantage of weaknesses in networks and how security professionals can use different technologies and security controls to defend against these threats.

I gained practical exposure to concepts such as **firewalls, network segmentation, secure protocols, packet capture, and packet analysis**. Tools such as Wireshark and tcpdump helped demonstrate how network traffic can be examined to identify suspicious or unusual activity. Google’s cybersecurity curriculum specifically includes packet capture and analysis as part of its practical training.

## 🐧 Linux and SQL

Another important part of my cybersecurity training is working with **Linux and SQL**.

Linux is widely used in cybersecurity environments, and learning how to navigate and manage a Linux system helped me become more comfortable working through the command line. I practiced commands for navigating directories, managing files, examining permissions, searching for information, and working with system resources.

I also learned new things about **SQL**, which is important for working with and investigating data stored in databases. Through SQL exercises, I practiced querying databases, filtering information, sorting results, and identifying specific records.

These skills are especially valuable in cybersecurity because security analysts often need to investigate large amounts of information, examine logs, and search for data that may indicate suspicious activity.

## 🛡️ Assets, Threats, and Vulnerabilities

Cybersecurity professionals need to understand what they are protecting, what could threaten those assets, and where weaknesses may exist. This section focuses on **assets, threats, vulnerabilities, and risk**.

Through these labs, I learned how to identify important organizational assets such as computers, servers, networks, applications, databases, and sensitive information. I also explored different types of threats, including malware, phishing, social engineering, unauthorized access, and other forms of cyberattacks.

I learned how vulnerabilities can create opportunities for attackers and why organizations need to continuously identify and address weaknesses in their systems.

Understanding the relationship between **assets, threats, vulnerabilities, and risks** helped me develop a more complete picture of how security incidents happen and how they can potentially be prevented.

## 🚨 Detection and Response: IDS, NIDS, and SIEM

A major part of cybersecurity is not only preventing attacks but also **detecting and responding to them**.

In this section, I explored **Intrusion Detection Systems (IDS)** and **Network Intrusion Detection Systems (NIDS)**. These technologies can monitor activity and help security teams identify potentially malicious or abnormal behavior.

I also learned about **Security Information and Event Management (SIEM)** systems. SIEM platforms collect and analyze security-related logs and events from different sources, allowing security analysts to investigate suspicious activity and identify potential security incidents.

Through hands-on exercises, I learned how security alerts can be investigated by examining logs, timestamps, IP addresses, usernames, event information, and other indicators. I also learned that cybersecurity analysts need to distinguish between normal activity, false positives, and genuine security threats.

This part of my portfolio demonstrates my developing ability to approach cybersecurity incidents from a detection and investigation perspective.

## 🐍 Python Automation for Cybersecurity

Another important skill I developed is **Python programming for cybersecurity automation**.

Python can help cybersecurity professionals automate repetitive tasks, process information, analyze data, and improve the efficiency of security operations. Instead of manually performing the same task repeatedly, scripts can be created to perform certain operations automatically.

In this section, I explored Python fundamentals and how programming can be applied to cybersecurity-related tasks. I worked with concepts such as variables, functions, loops, conditional statements, lists, strings, and file operations.

Learning Python helped me understand how automation can support cybersecurity professionals by reducing repetitive work and allowing analysts to focus more on investigation and decision-making.
